# Panel pentru iPhone

Versiune PWA separată a Panelului, instalabilă din Safari fără publicare în App Store.

## Adresă

`https://panel-pro.ro/`

## Redirect Discord necesar

Adaugă exact această adresă în Discord Developer Portal → OAuth2 → Redirects:

`https://panel-pro.ro/login.html`

Aplicația folosește aceeași configurație Supabase, aceeași bază de date și același sistem de roluri ca versiunea web.
