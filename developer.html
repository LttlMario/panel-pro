Publicarea unei versiuni noi

  1. Modifică version și releasedAt în js/project-version.js.
  2. Adaugă noua versiune în partea de sus din changelog.html.
  3. Scrie numai schimbări confirmate: funcții noi, îmbunătățiri și probleme rezolvate.
  4. Verifică Dashboard, Pontaj, Cereri, Rapoarte, Contracte, Admin și versiunea mobilă.
  5. Publică fișierele actualizate pe GitHub Pages și verifică dacă nu există fișiere vechi în cache.
  6. După fiecare modificare, creează o arhivă în panel-project-versions/vX.Y.Z-nume-actualizare/ cu manifestul, fișierele afectate, funcțiile Supabase și SQL-ul.

Arhive și rollback

Fiecare versiune publicată este păstrată în panel-project-versions/. În folderul versiunii găsești fișierele modificate, funcțiile Edge, migrarea SQL, commit-ul GitHub și statusul deploy-ului.

Deschide indexul arhivelor

Regula versiunilor

  • Patch: reparație fără funcție nouă, de exemplu 2.8.0 → 2.8.1.
  • Minor: funcție nouă compatibilă, de exemplu 2.8.0 → 2.9.0.
  • Major: refacere amplă sau schimbare incompatibilă, de exemplu 2.x.x → 3.0.0.

Fișiere globale

  • js/project-version.js — sursa unică a versiunii.
  • js/global-footer.js — footer-ul și fluxul donației.
  • css/global-footer.css — stilul footer-ului și ferestrei de donație.
  • changelog.html — istoricul public.
  • developer.html — această pagină, numai pentru Admin.
  • thank-you.html — confirmarea manuală după donație.

Mutarea pe alt server Discord

Toți pașii pentru aplicația Discord, server, roluri, webhook-uri, secrete Supabase și redeploy sunt centralizați într-un singur ghid.

  • MIGRARE-MULTI-ORGANIZATIE.md — instalare, securitate și administrarea organizațiilor.
  • js/discord-config.js — Client ID și scope-urile OAuth publice.
  • supabase/functions/.env.example — denumirile tuturor secretelor necesare.
Deschide ghidul platformei

Verificare înainte de publicare

  • Footer-ul apare o singură dată și la extremitatea de jos.
  • Butonul Revolut deschide pagina oficială într-un tab nou.
  • Confirmarea „Da, am donat” deschide pagina de mulțumire.
  • Utilizatorii obișnuiți nu pot vedea această pagină.
  • Numărul versiunii din footer corespunde changelog-ului.
