Ce mai trebuie făcut la mutarea Supabase

Interfața poate pregăti datele publice, însă un site GitHub Pages nu poate instala singur baza sau funcțiile fără cheia secretă de administrator.

  • 1️⃣ Rulează schema completă: supabase/MASTER-MULTI-ORGANIZATIE.sql, apoi migrarea de reparare a pontajelor.
  • 2️⃣ Publică cele 5 Edge Functions: sync-discord-role, manage-discord-config, manage-community-posts, send-discord-notification și close-expired-shifts.
  • 3️⃣ Configurează secretele Edge Functions: SUPABASE_SERVICE_ROLE_KEY (sau secret key), DISCORD_GUILD_ID și CRON_SECRET.
  • 4️⃣ Încarcă pe GitHub fișierul js/supabase-config.js descărcat mai sus.
  • 5️⃣ Deschide din nou configuratorul pe noul panel și salvează rolurile, webhook-urile, Guild ID-ul și Client ID-ul.
  • 6️⃣ Discord Developer Portal: adaugă URL-ul OAuth Redirect afișat mai sus.

Verificarea sistemului
